Upgates — design-intent cheat sheet

"Which of the ~686 SCSS variables can I change in the slot vs. the Designer admin vs. hand-override?" — 32 design intents, mapped.

How to read it
  • slot — change it in the custom-variables SCSS slot. System-wide, no CSS.
  • admin — change it in the Designer admin UI (color / brand system). NOT the slot.
  • override — no variable covers it; write an @layer override CSS rule by hand.
  • partial — split across layers (see notes).

Rule of thumb: try the slot variable first; only hand-override when no variable exists.
